# inbox-agent

LangGraph email assistant: agents spent their mornings answering repetitive buyer emails.

## What it does

- LangGraph agent that classifies emails, drafts replies from listing data and books viewings
- Every draft waits for an agent's approval before it is sent

## Results

- drafts accepted without edits: 60%
- average reply time: from 6 hours to 45 minutes
